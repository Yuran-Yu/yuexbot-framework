# YuexBot 原生插件 SDK 开发指南

当前正式版推荐使用 YuexBot 原生 x64 DLL 插件。插件 DLL 放入 `main/plugin` 目录后，可在「插件管理」页面启用、禁用、重载、删除、打开插件设置，并通过「配置」按钮编辑插件标准配置。

小栗子插件兼容层目前作为备用方案暂停，不作为当前正式版主线加载方式。

## 基本文件

一个插件通常包含：

- `my_plugin.dll`：插件 DLL。
- `my_plugin.json`：插件声明文件，建议和插件 id 保持一致。
- 可选数据目录：通过 `get_data_dir(plugin_id)` 获取，实际位于 `main/data/plugins/<plugin_id>`。

推荐从模板开始：

```powershell
copy sdk\plugin_template.cpp plugin\my_plugin.cpp
copy sdk\plugin_template.json plugin\my_plugin.json
```

## 必须导出的函数

```cpp
YUEX_PLUGIN_EXPORT int YUEX_PLUGIN_CALL yuex_plugin_get_info(YuexPluginInfo* info);
YUEX_PLUGIN_EXPORT int YUEX_PLUGIN_CALL yuex_plugin_init(const YuexBotApi* api);
YUEX_PLUGIN_EXPORT void YUEX_PLUGIN_CALL yuex_plugin_shutdown();
YUEX_PLUGIN_EXPORT int YUEX_PLUGIN_CALL yuex_plugin_on_event(int event_type, const char* event_json);
```

如果插件有自己的设置窗口，可以额外导出：

```cpp
YUEX_PLUGIN_EXPORT int YUEX_PLUGIN_CALL yuex_plugin_open_settings();
```

## 编译命令

在 `main` 目录下执行：

```powershell
D:\易语言\web开发\mingw64\bin\g++.exe -O2 -std=c++17 -finput-charset=UTF-8 -fexec-charset=UTF-8 -I. -shared -static plugin\my_plugin.cpp -o plugin\my_plugin.dll
```

注意：

- 当前主程序是 x64，插件也必须编译为 x64。
- x86/32 位 DLL 不能直接载入 x64 主程序。
- 源码和 JSON 建议保存为 UTF-8。

## 插件声明

`plugin/my_plugin.json` 示例：

```json
{
  "permissions": ["events", "onebot_api", "send_message", "config", "data_dir"]
}
```

常用权限：

- `events`：接收事件。
- `onebot_api`：调用 OneBot API。
- `send_message`：发送私聊/群聊消息。
- `config`：读写插件配置。
- `data_dir`：获取插件数据目录。

插件默认接收全部 OneBot 消息和事件，包括消息、通知、请求和元事件。框架不再在 UI 中提供
事件订阅配置，避免误关事件导致插件无响应。插件应在 `yuex_plugin_on_event` 内部自行判断
需要处理的事件类型，不相关事件直接返回 `0`。

## 多账号写法

插件收到的 `event_json` 会包含：

- `account_id`
- `account_name`
- `self_id`
- `group_id`
- `group_name`
- `sender_id`
- `sender_name`
- `message_id`
- `post_type`
- `message_type`

回复消息时优先使用带 `_as` 的 API，把事件里的 `account_id` 传回去：

```cpp
api->send_group_msg_as(account_id, group_id, "收到");
```

## 易语言 / 小栗子插件的作者与版本显示

易语言 / 小栗子 AppStart 模式插件（导出 `_AppStart`、`_OnGroup` 等）通过调用 SDK 的
`置应用名`/`置应用作者`/`置应用版本`/`置应用说明` 把信息写进静态链接的 SDK 内部，
这些值不会以宿主能读回的方式导出，而且易语言编译出的 DLL 通常没有 PE 版本资源，
所以框架无法自动识别这类插件的作者和版本。

要让作者、版本在「插件管理」里正常显示，请在插件 DLL 同目录放一个 UTF-8 的 JSON 旁挂文件。
宿主会按顺序查找：`<名称>.info.json`、`<名称>.meta.json`、`<名称>.json`。

```json
{
  "name": "月溪Sky",
  "author": "月溪",
  "version": "5.1.7",
  "sdkv": "5.1.7",
  "description": "小栗子易语言示例插件"
}
```

`YuexPluginHost32.exe` 读取元数据的优先级：

1. 插件通过 SetApp* 回调主动推送的值（C++ 插件可用）。
2. 上面的旁挂 JSON 文件。
3. PE 版本资源（`FileVersion`/`ProductName` 等，C++ `apprun` 插件通常带）。
4. 最后退回使用 DLL 文件名。

模板见 `sdk/plugin_metadata.info.json`。
